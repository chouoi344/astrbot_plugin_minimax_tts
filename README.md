# MiniMax 语音助手 v0.1.10

通过终逢小站调用 MiniMax，填写中转站 API Key 即可使用内置音色。

## 安装与使用

1. 在 AstrBot 的插件管理页面上传本插件 ZIP，然后启用或重载。
2. 在设置面板填写臭屁小站的 API Key，以及根据站内音色人设库选择对应的音色名称。
3. 默认音量倍数为 `1.0`，语言为“不启用语言增强”。
4. 使用过程中请确保创建了终逢中转站中的语音专属分组api key
5. 需要注意的是不支持微信机器人通道。

## 原有工具和指令

本次保留 `main.py` 原有工具和指令实现：

- `tts_say <文本>`：手动合成语音。
- `tts_speak(text)`：大模型自行决定是否调用的语音工具。
- `tts_status`：查看运行状态。
- `tts_segment_on` / `tts_segment_off`：控制当前会话分段。
- `tts_off` / `tts_all_off`：关闭自动语音转换，不影响手动指令和语音工具。

## 音色维护

后续上传的新音色可以通过更新插件的方式进行获取，可以点击更新，完成后记得看到新的音色。

## 插件介绍

本插件由“臭屁”制作，只适用于终逢小站的用户，后台内置的是中转的URL，如需接入其他语音模型，可以搜索“木有枝”大佬的情绪路由插件
